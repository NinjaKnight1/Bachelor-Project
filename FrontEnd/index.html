Check an LTLf property

Use F for “eventually”, sink for process completion, and the variables from your diagram.

Examples

  • F sink — a completed execution exists.
  • F (Confirm != true) — Confirm can be false.
  • F (Clothing == "Winter Jacket") — the specified value can be assigned.
  • F (sink && (Confirm == true)) — the process can finish with Confirm true.
